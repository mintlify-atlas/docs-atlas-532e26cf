PojavLauncher is an open-source Minecraft: Java Edition launcher for Android, built on the foundations of the original Boardwalk project. It runs the full, unmodified Java Edition client on ARM and x86 Android devices — including mods, modpacks, and custom resource packs — without requiring a PC.

## What PojavLauncher can do

PojavLauncher translates the Java AWT/OpenGL surface Minecraft expects into a native Android surface, then bridges touch and gamepad input to GLFW keyboard/mouse events. The result is the real Java Edition — not Bedrock, not a port.

## Quick start

<Steps>
  <Step title="Install PojavLauncher">
    Download the latest APK from [GitHub Releases](https://github.com/PojavLauncherTeam/PojavLauncher/releases) or install from [Google Play](https://play.google.com/store/apps/details?id=net.kdt.pojavlaunch). Grant storage permission when prompted.
  </Step>
  <Step title="Sign in">
    Open the launcher and tap the account selector at the top. Choose **Microsoft login** to sign in with your Xbox Live / Minecraft account, or **Local account** to play offline.
  </Step>
  <Step title="Pick a version">
    Tap the version selector and choose a Minecraft version. PojavLauncher downloads and caches game files automatically on first launch.
  </Step>
  <Step title="Play">
    Tap **Play**. The game launches with the default touch-control layout. See [Custom Controls](/guides/controls) to adjust buttons to your preference.
  </Step>
</Steps>
